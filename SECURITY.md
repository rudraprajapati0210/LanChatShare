# Reporting a security concern

Use [GitHub's private vulnerability form](https://github.com/rudraprajapati0210/LanChatShare/security/advisories/new). Include the affected release or commit, Android version, which side of the transfer was affected and the smallest reproduction using fictional data. If the form is unavailable, open an issue asking for a private contact channel and leave out vulnerability details.

The current prerelease is the supported target for reports. The maintainer will confirm the report privately, investigate its scope, coordinate a fix and credit reporters who wish to be named.

Bluetooth pairing pins the remote identity after human verification. The pinned identity authorizes TLS credentials for local Wi-Fi traffic. File access requires a grant and received files are verified before completion. Android Keystore protects device credentials where supported. Files and messages reside on the participating phones. Anyone able to unlock a phone may be able to read local content. [Protocol](docs/PROTOCOL.md)

Never attach device keys, keystores, pairing tokens, hotspot passphrases, private conversations or unredacted device logs. Debug benchmark sockets carry synthetic bytes only.
