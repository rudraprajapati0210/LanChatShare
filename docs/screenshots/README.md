# Screenshot contributions

Use an emulator or two test phones with fictional names, conversations and files. Capture the app at its native resolution. Remove notification previews, credentials, filenames and addresses that could identify anyone. Save a PNG here, add descriptive alt text in the root README and record the device, Android version and theme in the pull request.

The existing Share and Appearance screenshots were captured on an API 37 emulator. The conversation and active-transfer slots in the README are open for physical-phone captures.
